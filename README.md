# Emmanuella Arthur — Portfolio

Plain HTML, CSS and JavaScript. No build step. Open `index.html` or run `python3 -m http.server 5500`.

## Files
- `index.html` — all content (edit text here)
- `assets/css/variables.css` — colours and fonts (change the look in one place)
- `assets/css/style.css`, `responsive.css` — layout
- `assets/js/theme.js` (light/dark), `app.js` (menu, animations, form)
- `assets/images/me/` — your photos · `assets/cv/` — your CV
- `data/*.json` — reference copies of the content

## Things to personalise
- **Live project links:** see the comment under the project grid in `index.html`.
- **GitHub / LinkedIn:** add an `<a>` in the contact list and footer once you have the real URLs.
- **Contact form:** opens the visitor's email app, pre-filled. To receive messages directly, connect Formspree or EmailJS in `app.js`.
- **Screenshots:** swap the illustrated project thumbnails (`.thumb svg`) for `<img>` tags of your real screenshots.
